PLAYER-VISIBLE ARC · STANDARD · 7 ROUNDS

↶ CALLBACK

The party game that remembers everything.
The room invents an Anchor, gives it a Voice, builds an independent World, and then watches those winning ideas collide. Social prediction rounds hide backstage latency without ever making AI authoritative.

ROUND 1THE SEED

Players do
Invent one reusable character, product, object, place, business, vehicle, or mascot.
Room decides
Anonymous applause picks the winner or tied winners.
Creates ANCHOR memory
Winning Anchor image starts backstage. A concept card is always available.

ROUND 2READ THE ROOM

Players do
Make a private choice, then predict the entire room's distribution.
Server scores
Accuracy against the room's real choices.
A fast social beat that hides Anchor-image latency.

ROUND 3MAKE IT REAL

Players see
The winning Anchor image or deterministic concept-card fallback.
Players do
Write what the established Anchor says.
Creates VOICE memory
Graph edge: ANCHOR — SAYS → VOICE.

ROUND 4THE CATCH

Players do
Build an independent World under one mechanically checked comedy constraint.
Quality gate
Invalid answers can be revised before the deadline.
Creates WORLD memory
Graph edge: WORLD — COLLIDES WITH → ANCHOR.

ROUND 5CROWD CONTROL

Players do
Point at one player, then predict the group's full distribution.
Server scores
Prediction accuracy—never AI judgment.
A second social beat that gives callback preparation time to finish.

ROUND 6CALLBACK

Prompt uses
The room's ANCHOR + VOICE + WORLD in one causal setup.
Players do
Answer the open consequence question; source authors can earn royalties.
Creates CONSEQUENCE memory
Safe candidate or deterministic fallback. AI never scores.

ROUND 7 · FINALTHE REMIX

Prompt uses
Three or four compatible established memories from tonight.
Players do
Write and vote on the final answer while the masterpiece resolves.
Final scores + winners

POST-GAMETONIGHT'S LORE

Room sees
Standings, awards, the connected memory graph, and Tonight's Masterpiece.
Next
Play again, finish, or enter the optional Monster Factory encore.
Every match remains finishable when AI, image generation, storage, or a client connection fails.
