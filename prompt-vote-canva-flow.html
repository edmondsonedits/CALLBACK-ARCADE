PROPOSED REVISION · 3 ROUNDS · ALL PLAYERS CREATE

PROMPT & CIRCUMSTANCE

Write the scene. Win the room. Watch it become an image.
Core mechanicEvery player submits one short visual prompt. The prompts are shown anonymously, the room votes for the best one, and the winning prompt is locked before image generation begins.

STEP 1SUBMIT

Every player
Writes one visually clear scene in 12 words or fewer.
Simple recipe
Someone → Action → Place. No image-generation jargon required.
Prompts stay private until the answer lock.

STEP 2VALIDATE

Server checks
Room, role, phase, ownership, length, safety, and duplicate actions.
Eligible set
Only safe, valid prompts can appear on the voting screen.
The client never decides which prompts qualify.

STEP 3VOTE

The room sees
Every eligible prompt in a shuffled, anonymous order.
Each player
Votes for the one scene they most want to see generated.
No self-voting

STEP 4LOCK WINNER

Server tallies
Official votes determine the top prompt before generation starts.
If tied
One quick runoff among tied leaders; a remaining tie uses a stable server tiebreak.
Winning prompt is final

STEP 5GENERATE

Backstage job
Only the winning prompt is sent to the image provider and stored through the authenticated media path.
Failure path
Timeout, provider failure, or storage failure becomes a deterministic concept card.
Generation can never change the winner or award points.

STEP 6REVEAL

Big-screen moment
Reveal the image, the winning prompt, its author, and the final vote count.
Round result
Award vote-based prompt points through uniquely keyed score events.
Next round or final gallery
DESIGN PRINCIPLES
Direct choiceThe room chooses what gets generated; there is no hidden featured prompt.
Anonymous firstAuthorship stays hidden through voting and is revealed only after the winner locks.
Always playableA concept card keeps the reveal and scoring intact when image services fail.
Clean revisionThis replaces the current decoy-and-guessing loop with submit → vote → generate.
