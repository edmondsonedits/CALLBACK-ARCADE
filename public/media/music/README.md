# King Prompter soundtrack

The five numbered MP3 files are normalized, 48 kHz, 160 kbps delivery copies of the user-provided WAV sources. The originals remain untouched in the user's Downloads folder.

Source order:

1. `Medieval Background Music (2).wav`
2. `Medieval Background Music (1).wav`
3. `Medieval Background Music.wav`
4. `Medieval Game Music (1).wav`
5. `Medieval Game Music.wav`

The menu rotates through all five tracks. Game-specific assignments live in `lib/game/soundtrack.ts` and can be changed without editing the playback code.
