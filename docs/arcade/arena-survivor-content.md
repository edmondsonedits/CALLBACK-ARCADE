# Arena Survivor content notes

Arena Survivor is a short party-game quiz, not emergency training. Each scenario has a fixed answer key in `server/arcade/arena_survivor.ts`; the room shows the result only after choices lock. Content is paraphrased for play and should not replace current instructions from emergency services. Reviewed 2026-09-28.

| Scenario | Content guardrail | Reference |
| --- | --- | --- |
| Avalanche | Present getting off the moving slab/slide as a possible action, never a guaranteed safe route. | [Avalanche.org: Avalanche Rescue](https://avalanche.org/avalanche-tutorial/avalanche-rescue.php) |
| Desert Survival | Tell lost players to contact help/share location and stay put when safe; shade and reduced exertion limit heat exposure. | [National Park Service: Big Bend safety](https://home.nps.gov/bibe/planyourvisit/safety.htm), [NPS Outdoor Emergency Plan](https://www.nps.gov/subjects/healthandsafety/upload/NPS-Outdoor-Emergency-Plan-508c.pdf) |
| Shipwreck | Keep the life jacket on; stay with a capsized boat if it remains afloat and signal rescuers. | [U.S. Coast Guard: Safety and Survival Card](https://www.dco.uscg.mil/Portals/9/DCO%20Documents/5p/CG-5PC/CG-CVC/CVC3/references/Safety_Equip_Survival_Card.pdf) |
| Storm Blackout | Prefer flashlight or battery lantern over candles; never approach downed lines. | [USFA: Candle safety](https://www.usfa.fema.gov/prevention/home-fires/prevent-fires/candle/), [NWS: Thunderstorm safety](https://www.weather.gov/safety/thunderstorm-during) |
| Smoke in the Hall | Use stairs only if the exit route is clear; if unable to exit safely, close the door, call emergency services, and signal for help. | [USFA: Apartment fire safety](https://www.usfa.fema.gov/downloads/fief/apartment_fire_safety.pdf) |
| Thin Ice | Use the short “shout, grab, kick, roll” sequence; keep weight spread out after reaching the ice. | [American Red Cross: Ice safety lesson](https://www.redcross.org/content/dam/redcross/training-services/whale-tales/pdfs/Lesson_9_FINAL.pdf) |
| Wildfire | Follow evacuation orders and designated routes; if trapped, call emergency services and share location. Avoid presenting a nearby clearing as universally safe. | [Ready.gov: Wildfire information sheet](https://www.ready.gov/sites/default/files/2024-08/ready-gov_wildfire_info-sheet.pdf) |
| Rip Current | Do not fight the current; float/tread water and signal for help, then swim parallel only if able. | [NOAA National Hurricane Center: Rip current survival](https://www.nhc.noaa.gov/rip-currents/survive.html) |

This note tracks the sources used to review this game's brief scenarios. It is not a complete emergency-response curriculum or a substitute for local authority guidance.
