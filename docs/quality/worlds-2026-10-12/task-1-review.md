## Findings

1. **P2 — Changing contestant count through the preserved API corrupts Tour scores.** `games/royal-ballistix/source/index.html:331` (`setPlayerCount`) rebuilds `P` and ordinary wins but leaves `G.tour.points`, index and completed count untouched. The points array is sized only in `startMatch` at line 466, while `awardTour` at line 293 adds to every current player's entry without initializing it. Reproduced with a four-seat Tour, `RoyalBallistix.setPlayerCount(10)`, then a timeout: points become `[10,10,10,10,NaN,NaN,NaN,NaN,NaN,NaN]`, and the actual standings formatter displays `PIP · NaN points` through `WREN · NaN points`. Calling the API is expressly documented to retain immediate reset semantics (`games/royal-ballistix/integration/README.md`, Worlds section). Restart/reconcile the Tour when its roster changes, including accumulated scores and progress, so 2–10-seat integration remains valid.

2. **P2 — Starting a match replays held exhibition volleys as live audio and retains exhibition shake.** `games/royal-ballistix/source/index.html:466` sets `G.demo=false` and unlocks audio before `restart` invokes `resetRound` at line 334. That reset first releases every old paddle's held balls through `releaseMag` at line 359; this calls `tone` with demo suppression already disabled. It also never resets `G.shake`, which `draw` reads at line 440. A focused reproduction with one demo bot holding one ball yielded zero tones during the demo but one live oscillator immediately after `startMatch('siege')`, although the new match had zero balls and was still counting down. Fresh Start should dispose of demo-held state without executing gameplay feedback and reset transient shake. This is a transition leak, not a claim that idle exhibition audio plays by itself.

3. **P3 — Defender-name editing rewrites the native input on each keystroke.** `games/royal-ballistix/source/index.html:489` calls `cleanName` and `savePreferences` from `oninput`; `cleanName` at line 309 trims spaces and substitutes `YOU` for empty text, and `syncPreferences` at line 315 writes that result back into the focused field. Reproduced `Ada ` becoming `Ada` immediately and an emptied field becoming `YOU`. A user typing a multiword name loses the separating space before the next character; deleting the current value does not leave an editable empty field. Preserve the editing buffer and normalize on blur/change/save, or otherwise avoid rewriting the active text input.

4. **P2 — Browser evidence upload skips the hidden output directory in the reviewed revision (known, fix in progress).** `.github/workflows/browser-worlds.yml:29–34` uploads `.browser-worlds/` using `actions/upload-artifact@v4` without `include-hidden-files: true`; `scripts/browser-worlds/run.mjs:12` chooses that hidden directory. The parent reports a completed browser CI run on remote `2c7c0b8` (tree equivalent to local `22bdb34`) with all desktop/portrait/landscape checks passing and no runtime errors, but no retained screenshots because the uploader excludes hidden files by default. Explicitly include the hidden output and fail if it is absent, then rerun to obtain the required visual-review artifacts. The implementer is already applying this workflow correction; it is not part of the `12adb6e` source reviewed here.
