# Crownway Coach v1.5.0 evidence

`verification.json` records focused behavioral, actual-course, navigation, camera and CPU-side modeled pose/resource checks with hashes for every manifest source path. This is game quality evidence, **not multiplayer verification**. The original archive and all bundled Three.js r180 files were byte-checked against their preserved/reference counterparts.

No new browser screenshot, frame-rate, hardware touch, audio or controller attestation is made. The known local Chromium socket startup restriction and cloud WebGL2 limitation prevent that scope here. Previous `quality/` and `navigation-review/` folders remain historical evidence, not current source attestations.

The coordinator owns catalog regeneration, whole-repository checks and deployment. See `docs/quality/sumo-benchmark/royal-roller-ruckus-report.md` for the source-grounded comparison and regression watch list.
