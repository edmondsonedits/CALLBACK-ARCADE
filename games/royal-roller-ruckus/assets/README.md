# Assets and provenance

This build requires no separate art, texture, model, music or recorded sound-effect assets.

- Track, cages, riders, particles, HUD and environment geometry are generated in code with Three.js.
- Prototype sound is generated at runtime with the Web Audio API.
- The game was created iteratively in the user's CALLBACK project chat from a user-supplied prototype and rebuilt as Royal Roller Ruckus. No Fusion Frenzy/Crash Bash artwork, characters, branded UI, music or proprietary source code is included.
- Three.js 0.180.0 is stored under `source/vendor/` under the MIT License.

Record creator/source, license or permission basis, and attribution requirements here before adding future authored assets.
