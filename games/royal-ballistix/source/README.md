# Standalone source

`index.html` is the complete imported game and remains directly playable without a build or runtime network dependency. Its import base is recoverable from repository commit `785a15000abe11970c7b92c5f3cab197061fcedf`; upstream origin and rights are recorded in `../assets/PROVENANCE.md` and `UPSTREAM-LICENSE.txt`.

The v0.13.0 Sumo benchmark revision adds setup/drill flow, gamepad, saved audio/access preferences and procedural court/defense feedback. It preserves the radial-stick mobile design (distance controls speed; no Run button), Magnet/Pulse controls, keyboard/API inputs, camera controls and CAM codes. See `../CHANGELOG.md` and `../tests/evidence/quality-review.md` for changes and verification limits. No Sumo reference content was imported.

The v0.14.0 Worlds revision adds four simulated courts, all-bot live title/Watch flow, a timed four-court Tour and grouped 16-control customization. `assets/` contains six actually used Kenney CC0 PNG/OGG files, upstream licenses and exact-file/archive provenance. These are optional local enhancements; missing files do not prevent play. The inline script remains the only script and all public camera/seat hooks remain.
