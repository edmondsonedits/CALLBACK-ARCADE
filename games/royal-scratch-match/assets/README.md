# Assets and provenance

Royal Scratch Match v0.5 has no external runtime asset files.

The imported standalone HTML draws the castle stage, contestants, note highway, HUD, particles, and other visuals with Canvas/CSS and uses browser Web Audio synthesis for prototype music and sound effects. Its inline grain effect is a data-URI SVG generated inside the source. No third-party images, music files, fonts, or libraries are loaded by source/index.html.

## Provenance and use

- Runtime source was created in the user's ChatGPT CALLBACK project and supplied by the user in this chat for inclusion in this repository.
- The user explicitly requested this repository/project use.
- No third-party runtime asset files were identified in the v0.5 source.
- The separate UI concept image generated earlier in the chat is not a runtime dependency and is intentionally not imported here.

If authored art or audio is added later, place it in this directory and record its creator/source, license or project-use authorization, and which source file consumes it.
