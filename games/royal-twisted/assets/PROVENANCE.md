# Asset provenance and usage rights

## Game-created content

Royal Twisted v0.5 does not depend on external character art, environment textures, branded UI, music files or commercial game assets. The medieval tower, contestants, hazard rods, particles, materials, procedural stone texture, UI and procedural audio are generated by the checked-in HTML/CSS/JavaScript implementation developed for this CALLBACK project.

The game is mechanically inspired by classic obstacle-reaction party games, but no Fuzion Frenzy artwork, characters, music, UI assets or source code are included.

## Three.js

The required `vendor/three.core.js` dependency is also included from the same r180 release under the same MIT license. Source: https://raw.githubusercontent.com/mrdoob/three.js/r180/build/three.core.js .

`vendor/three.module.js` is upstream Three.js r180 (npm 0.180.0), vendored unchanged from `mrdoob/three.js` tag `r180`, path `build/three.module.js`.

Three.js is distributed under the MIT License. The upstream license is retained as `vendor/three-LICENSE.txt`.

The chat build referenced the equivalent pinned module through jsDelivr. Vendoring it removes the runtime CDN dependency while preserving the rendering API version.
