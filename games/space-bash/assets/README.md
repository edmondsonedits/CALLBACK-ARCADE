# Assets

This imported Space Bash build has **no external asset files**.

All visible game artwork is drawn procedurally by source/index.html using Canvas 2D. Sound effects are synthesized at runtime with Web Audio, and vibration uses the browser vibration API when available.

## Provenance

The standalone implementation was created in this ChatGPT project under the user's direction. It uses original code/visual presentation inspired by general arcade/physics-party design principles. No Crash Bash artwork, characters, music, branded UI, proprietary source code, or third-party binary assets are included.

## Usage rights

There are no separately licensed third-party assets to track. Any future third-party asset must be added here with source, author/license, and permitted usage before use.
